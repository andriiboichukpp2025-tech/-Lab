# КаваLab

Навчальний MVP сайту кав'ярні українською мовою. Проєкт працює без бекенду: кошик, замовлення, тема й бронювання зберігаються у `localStorage` браузера.

## Запуск

Відкрийте проєкт через Live Server або інший локальний HTTP-сервер. `fetch()` для JSON не працює коректно при відкритті HTML через `file://`.

## Технології

- семантичний HTML5;
- Tailwind CSS Play CDN 3.4.17;
- чистий JavaScript ES-модулі;
- Swiper 11 і Fancybox 5 через CDN;
- Node.js `node:test` для чистих модулів.
- План залу у `data/tables.json` і чиста геометрія у `js/modules/floor-plan.js`.

## Перевірка

```bash
npm test
```

Тести охоплюють ціноутворення, URL-стан, бронювання, SEO-метадані та геометричні інваріанти плану залу.

У середовищі розробки Node.js має бути встановлений окремо.

## Важливо

Усі адреси, контакти, відгуки та фотографії є демонстраційними. Перед публікацією замініть демо-контент, додайте власні зображення та налаштуйте Vercel secrets. Production URL: `https://kava-lab-boichuk.vercel.app`.
