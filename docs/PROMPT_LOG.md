# Prompt log

## Фаза 1

- Завдання: створити каркас і спільні компоненти.
- Змінено: HTML-сторінки, стилі, базові модулі та SVG-активи.
- Перевірка: структура файлів; Node.js недоступний.

## Фаза 2

- Завдання: додати JSON-дані, меню, галерею та контакти.
- Змінено: `data/`, меню, Swiper, Fancybox, форма контактів.
- Перевірка: JSON успішно розібрані PowerShell.

## Фаза 3–4

- Завдання: конструктор, ціни, URL-стан, бронювання та кошик.
- Змінено: чисті модулі, SVG-карта, localStorage-потоки й тести.
- Перевірка: `git diff --check` і JSON; Node.js потребує встановлення.
