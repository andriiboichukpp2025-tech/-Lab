# Архітектура

## Потоки даних

JSON у `data/` завантажується через `js/modules/data.js`. Налаштування конструктора передається через URL, а кошик і бронювання зберігаються через `js/modules/storage.js`.

## Конструктор

`calculateDrink()` у `js/modules/pricing.js` перевіряє білий список основи, об'єму, молока, сиропів, додатків і кількості. Розрахунок виконується в копійках, а ціни в інтерфейсі форматуються перед показом.

## Бронювання

`reservation-logic.js` містить чисті функції перевірки дат, перетину інтервалів і детермінованої зайнятості. Зайнятість залежить від `tableId`, дати й часу, тому не змінюється під час перемальовування карти.

## Ключі localStorage

- `kavalab:theme`
- `kavalab:cart:v1`
- `kavalab:reservations:v1`
- `kavalab:orders:v1`
