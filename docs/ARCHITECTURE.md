# Архітектура

## Потоки даних

JSON у `data/` завантажується через `js/modules/data.js`. Налаштування конструктора передається через URL, а кошик і бронювання зберігаються через `js/modules/storage.js`. Динамічний DOM створюється через `textContent` для недовірених значень.

## Конструктор

`calculateDrink()` у `js/modules/pricing.js` перевіряє білий список основи, об'єму, молока, сиропів, додатків і кількості. Розрахунок виконується в копійках, а ціни в інтерфейсі форматуються перед показом.

## Бронювання

`reservation-logic.js` містить чисті функції перевірки дат, перетину інтервалів і детермінованої зайнятості. Зайнятість залежить від `tableId`, дати й часу, тому не змінюється під час перемальовування карти.

`data/tables.json` є єдиним джерелом плану залу у сантиметрах. `floor-plan.js` містить чисту геометрію столів, стільців, меблів, перетинів і clearance; `reservation.js` відповідає лише за SVG/UI-рендеринг, фільтри, zoom та вибір столика. Старі ID столиків не допускаються до нових бронювань і показуються як застарілі записи; видалення зберігається окремим ключем.

## Ключі localStorage

- `kavalab:theme`
- `kavalab:cart:v1`
- `kavalab:reservations:v1`
- `kavalab:legacy-reservations-dismissed:v1`
- `kavalab:orders:v1`
